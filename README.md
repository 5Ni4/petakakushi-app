# ぺたかくし

現在の版は **ver1.5**（Gitタグ `v1.5.0`）。過去の版はそのまま保存し、変更を版ごとに記録する。[変更履歴](CHANGELOG.md)と[バージョンの進め方](VERSIONING.md)を参照。

クレヨン風の14種類のスタンプでスクリーンショットを飾り、隠したい文字を覆う画像エディタ。

画像はファイル選択またはドロップから端末内で読み込み、ブラウザ内でPNGに合成する。元画像や加工後の画像を送信するAPI、アカウント登録、分析ツール、外部フォントは使わない。サイト配信自体にはSitesを使用する。

## 操作

- 画像を選び、スタンプをタップして追加。
- スタンプの上のタブで「すべて／ライン／矢印／イラスト」を切り替える。色の右隣のプルダウンでパレットを選び、4色から使う色をタップする。
- スタンプ一覧の見本は、現在のパレットと選んだ色に連動する。イラストの差し色も配置後と同じ配色になる。
- 指やマウスで移動。選択枠の右下で拡大縮小。
- 下のスライダーでサイズと回転を調整。帯・楕円は横幅だけ変更可能。
- 画像は2本指、または拡大ボタンで拡大。拡大時は空いた部分のドラッグで移動できる。手の切り替えでスタンプ上からも画像を動かせる。
- 重なり順のボタンで一覧を開く。上ほど手前で、↑↓で1段ずつ並べ替え。スタンプ名をタップすると選択して一覧を閉じる。
- 「…」から複製・最前面・最背面。順番の変更も「元に戻す」「やり直す」に対応。
- 「保存する」で合成済みPNGを確認し、ダウンロードまたはOSの共有画面へ。
- 保存画面の下の「ぺたかくしをXで紹介」で、紹介文とサイトURL入りの投稿画面へ。投稿は利用者が行う。
- キーボードの矢印で1px移動、Shift併用で10px。Deleteで削除。Cmd/Ctrl+Zで元に戻す。

## 画像とプライバシー

Xの紹介リンクは固定の紹介文とサイトURLだけを渡す。写真、書き出したPNG、編集履歴、現在のページのクエリなどは使わない。外部ウィジェットや投稿APIは読み込まない。[Xの公式Web Intent仕様](https://docs.x.com/x-for-websites/web-intents/overview)に沿った通常のリンクで、投稿画面を別タブで開く。サイトの閲覧範囲はSites側の共有設定で管理する。

16メガピクセル・長辺8192px以内の画像は元のピクセル寸法を維持。それを超える画像は読み込み時に縮小し、実際の寸法を画面表示する。入力ファイルは60MBまで。状態はメモリ内にのみ保持し、ページを再読み込みすると失われる。

塗りつぶした形の内側は不透明。輪郭・しずく間のすきま・線の空白・チーズ外周のくぼみは覆わない。隠したい文字を十分内側へ収める必要がある。SVG内部のかすれは不透明な本体の上に明暗を重ねる構成。加工した画像は新規CanvasからPNG化し、元画像のレイヤーや元メタデータを引き継がない。

端末メモリ対策として、表示中のスタンプと直近4色分の画像だけを保持する。古い履歴に戻すときは必要な素材を再生成してから表示を更新する。スタンプは最大60個、履歴は60操作。

## 開発と検証

`npm run dev` / `npm run build` / `npx tsc --noEmit`

`node --test tests/editor.test.ts` で履歴・寸法制限・画像化・不透明な内部領域を検証。

`node scripts/prepare-assets.ts` で承認済みSVGから元のサムネイルと全パレット用の224枚の見本を作成。素材やパレット変更時は再生成し、`stampPreviewUrl`の見本版番号も更新する。通常の見本は小さなPNGを使用し、WebMCPで指定された独自色だけ端末内で小さなSVG見本を作る。

WebMCP対応環境では状態確認・スタンプ追加・書き出しプレビューの準備を同じUI操作に接続する。ファイルの選択や共有はユーザーが行う。今回の環境では対応WebMCP検証コンテキストを見つけられず、実際の登録・実行は未確認。iPhone Safari実機やブラウザの操作・表示テストも未実施。
